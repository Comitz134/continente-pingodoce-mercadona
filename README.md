# Prato da Semana 🍽️

App mobile-first que gera uma ementa semanal de receitas (com fotos) filtrada
por orçamento, alergias, alimentos a evitar e lojas (Continente, Pingo Doce,
Mercadona), com carrinho de compras e comparação de preços por loja.

- `receitas/` — a app (HTML/CSS/JS + PWA), publicada no GitHub Pages.
- `backend/` — scrapers das 3 lojas + API (FastAPI) e histórico de preços.
- `.github/workflows/` — deploy para Pages e recolha agendada de preços.

Publicação e configuração do Supabase: ver [DEPLOY.md](DEPLOY.md).
